
# Production Studio Drum Kit

Homework 1: Modernizing a legacy drum kit using
React 19, Vite, keyboard event handling, and
WCAG 2.2 AA accessibility practices.

## Requirements

- Node.js 20.19+ or 22.12+
  (or a newer compatible version)
- npm

## Start

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
